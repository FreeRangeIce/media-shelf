# Platform badge assets — sources and trademark notes

These files are used as small (24px) badges on video-game grid tiles. Original
proportions are kept (`object-fit: contain`). Colors are left as in the source
file; none of these marks were redrawn, recolored, or converted to monochrome
white. Berean should review trademark use before release.

## Assets included

### xbox.svg — Xbox (also Xbox 360, Xbox One, Series X|S)

- Source URL (Wikimedia Commons): https://commons.wikimedia.org/wiki/File:Xbox_logo_(2019).svg
- File URL used: https://upload.wikimedia.org/wikipedia/commons/ (Commons Special:Redirect/file/Xbox_logo_(2019).svg)
- Documented origin: uploaded 7 May 2020 as a work by Microsoft Corporation from https://www.xbox.com/en-US/
- License note on Commons: public-domain text logo (threshold of originality); **trademarked** (Microsoft / Xbox). The 7 July 2021 Commons revision is an optimization of that upload.
- Official color used as-is (the 2019 Xbox sphere). A white monochrome variant exists in Microsoft brand materials but was not applied here.

### playstation.svg — PlayStation (PSN, PS1, PS2, PS3, PS4, PS5)

- Source URL (Wikimedia Commons): https://commons.wikimedia.org/wiki/File:PlayStation_logo.svg
- Documented origin: http://www.playstation.com ; author Sony Interactive Entertainment (Commons file page).
- License note on Commons: public-domain text logo (threshold of originality); **trademarked** (Sony Interactive Entertainment / PlayStation).
- Official artwork used as-is. A family mark is used for every PlayStation-family platform in the app; no per-generation logo was invented.

### switch.svg — Nintendo Switch

- First-party source URL: https://www.nintendo.co.jp/common/v2/img/ncommon/_common/logo/switch.svg
- Retrieved directly from Nintendo's official site (HTTP 200, `image/svg+xml`). Also catalogued on Commons as File:Nintendo_Switch_logo.svg, which credits the same official URL.
- License / trademark: official Nintendo artwork; **trademarked** (Nintendo / Nintendo Switch). Copyright status is not treated as a free license. Colors and proportions left unchanged. Nintendo brand use needs review before release.

## Text-abbreviation fallbacks (no verified official asset used)

A neutral text badge is used when no official, clearly provenanced mark could be verified for a 24px disc, or when the only official file is a wide wordmark that would have to be cropped or invented to fit.

| Platform (app value) | Badge text | Reason |
| --- | --- | --- |
| Steam | Steam | Official first-party wordmark exists at https://community.steamstatic.com/public/shared/images/header/logo_steam.svg (Steam/Valve CDN). That lockup is a wide wordmark, not a square mark. Wikimedia's "Steam icon logo.svg" is documented as a *combination* of other files, so it was not used (not official artwork; the brief forbids inventing or compositing a logo). Valve branding also requires approved artwork and that the logo stand alone. |
| Switch 2 | NS2 | No official logo file was found at Nintendo's first-party logo path (`…/logo/switch2.svg` and `…/logo/switch-2.svg` both 404). |
| GameCube | GCN | No official logo file was found at Nintendo's first-party logo path (`…/logo/gamecube.svg` 404). Other guessed official URLs also 404. |
| PC | PC | There is no official "PC" platform logo. |
| Other | OTH | Catch-all; no brand mark. |

## Not used

- Wikimedia "Steam icon logo.svg" — source is a combination of other files, not official Valve artwork.
- Any monochrome/white conversion of the marks above.
- Any self-drawn or traced logo.
