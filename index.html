    How it works on iPhone

    Back up

    1. Tap Back up to iCloud.
    2. In the share sheet, choose Save to Files.
    3. Pick iCloud Drive, choose a folder (for example “Media Shelf”), then tap Save.

    Restore

    1. Tap Restore from iCloud.
    2. In Files, tap Browse → iCloud Drive and pick your media-shelf-backup-….json file.
    3. Choose Merge (keep what’s here and add from the backup) or Replace (swap your library for the backup).

    On a computer (or a browser without a share sheet), the backup downloads as a file instead — move it to iCloud Drive or another safe place.

    Improve Lookup

    Optional free API keys unlock better movie posters (OMDb) and game covers (RAWG). Keys stay in this browser only — never uploaded. Lookup still works without them.

    Movies (OMDb)

    Not set

    An API key is a free password that lets Media Shelf ask OMDb for IMDb-quality posters and titles. Stored only in this browser. Without it, movie Lookup still uses iTunes + Wikipedia.

    1. Click Get free key (opens OMDb signup).
    2. Register and verify your email.
    3. Copy the key from OMDb’s confirmation / account page.
    4. Paste it below and press Save.

    Not set

    A free RAWG developer key unlocks deep game covers and metadata. Stored only in this browser. Without it, game Lookup still uses iTunes + Wikipedia.

    1. Click Get free key (opens RAWG API docs).
    2. Create / sign in to a RAWG account from the docs or site.
    3. Create an API key in your RAWG developer / account area, then copy it.
    4. Paste it below and press Save.
