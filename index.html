    How it works on iPhone

    Back up

    1. Tap Back up (save a file) (or Back up at the top of the page).
    2. In the share sheet, choose Save to Files.
    3. Pick iCloud Drive, choose a folder (for example “Media Shelf”), then tap Save.
    4. Open the Files app to check the file is there. Media Shelf can’t see where the share sheet saved it.

    Restore

    1. Tap Restore from file.
    2. In the file picker, tap Browse → iCloud Drive and pick your media-shelf-backup-….json file.
    3. Choose Merge (keep what’s here and add from the backup) or Replace (swap your library for the backup). If this browser has no items yet, just tap Restore.

    On a computer, the backup usually downloads as a file — move it to iCloud Drive or another safe place. If your browser opens a share menu instead, pick a place to save it, or use Export to download a copy.

    Improve Lookup

    Optional free API keys let movie Lookup check OMDb first, and game Lookup try RAWG first. Keys are saved only in this browser and aren’t included in backups. When you use Lookup or Test, your browser sends the key directly to OMDb or RAWG. Media Shelf has no server. Book Lookup works without keys. Movie and game Lookup without keys is limited.

    Movies (OMDb)

    Not set

    OMDb gives out free API keys (up to 1,000 requests a day). With a key, movie Lookup checks OMDb first for poster, title, year and director. Saved in this browser. Sent only to OMDb, when you use Lookup or Test. Without a key, movie Lookup tries iTunes and Wikipedia. Results are hit-or-miss: check the match or paste a cover URL.

    1. Tap Get free key (opens omdbapi.com).
    2. Choose FREE! (1,000 daily limit), enter your email, name and a short description of use, then Submit.
    3. OMDb emails you the key. Follow any instructions in that email.
    4. Paste the key below and press Save.
